# N05 implementation evidence — 2026-10-27

N05 implements persisted semantic locators, a read-only preview picker/tester and scoped Windows UIA read/invoke/value/selection through a dedicated COM worker. See the [contract and operator guide](../native-locators.md).

## Local evidence

- TypeScript check and **332 tests across 26 files** pass. New cases cover persisted pointer-free locators, desktop/browser validation, explicit targeting mode changes, semantic adapter routing without coordinate input, structured error propagation, preview transforms and stale geometry.
- **24 Linux Rust tests** pass, including three portable UIA contract/policy cases and curated error/redaction coverage. These tests do not call Windows UIA.
- The full Windows helper and Win32 fixture cross-compile with `cargo check --target x86_64-pc-windows-gnu`. This is compile evidence only.
- Renderer acceptance covers semantic fields, unique/missing/ambiguous results, late response invalidation, read-only preview picking, saved-locator reload, modal close and explicit coordinate mode. This uses a controlled API, not Windows provider access. Screenshots are written to `test-results/relay-native-picker.png` and `test-results/relay-native-locator.png`.
- Production build and source Electron IPC/SQLite/engine smoke pass locally. Native inspection has explicit preload/main/utility routes and rejects invalid locators/unknown targets.

## Hosted and manual qualification

The first qualified [hosted Windows run](https://github.com/ianwijma/desktop-automation-software/actions/runs/40386760800) at `12b85a1` passes **57/57 scenarios**: the existing 45 plus four UIA cases in each of the three Win32 fixture variants. The native reports observe read-only picking, stable locators after movement, Invoke, Unicode Value/read, SelectionItem, duplicate/disabled/secure/read-only rejection, modal blocking and removed-control outcomes.

CI also exposed an existing X11 `xdotool mousemove --sync` stall after cancellation. A persistent-client Xvfb probe reproduced the unchanged-position hang. Movement now queries the resulting position through the same connection instead of waiting for movement away from the old point, with an explicit repeated-position regression test. See [upstream explanation](https://github.com/jordansissel/xdotool/pull/464). A separate extension-frame regression measured bounds before waiting for paint and could return an old offset. The shared mapper now measures after the wait, with deterministic managed/extension tests that move the frame between callbacks. No click is retried. The macOS AX window-lookup regression now retries only temporarily absent read-only metadata up to three snapshots; ambiguity and input actions never retry.

The Windows matrix attempts the added UIA cases in each Win32 fixture variant. CI artifacts and the PR record identify the tested head and actual results; unexecuted or unavailable cases are not passing evidence. The existing Linux Xvfb, macOS and browser checks remain regression coverage.

This development host is Linux/X11. Real Windows 11 and representative WPF/WinUI/Electron/providers, actual virtualized lists, multi-process hosting, elevated/locked desktops, mixed displays and installed-app behavior have **not** been qualified locally. Virtualized/secure/disabled/offscreen/modal outcomes are explicit; supporting automatic realization, secure input, arbitrary native recording or other UIA patterns is not implied. Use the [manual report](../manual-test-report.md) for future platform qualification.

N05 is implemented; N06 (macOS AX targeting) is the next slice. N07 adds AT-SPI through the same persisted semantic contract, and A01 remains independent.
