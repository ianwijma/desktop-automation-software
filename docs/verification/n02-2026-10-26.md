# N02 implementation evidence — 2026-10-26

N02 replaces Windows per-request PowerShell/C# with a persistent Rust Windows Graphics Capture/checked SendInput backend. PrintWindow remains explicit. Protocol 2 carries source offsets, DPI and capture-resource cleanup; old native helpers are rejected before automation. See the [backend guide](../windows-native.md).

## Local checks

- `npm run check`: TypeScript check and **315 tests across 25 files** pass. Added contracts cover explicit legacy capture selection, no fallback, crop offsets, DPI/backend invalidation and input-free passive cleanup.
- `cargo test --manifest-path native/Cargo.toml`: **4 portable Rust tests** pass, including negative virtual-desktop coordinates and complete chord validation.
- `cargo check --manifest-path native/Cargo.toml --all-targets --target x86_64-pc-windows-gnu`: Windows backend, Win32 fixture and Windows-only partial-SendInput ownership tests compile. This is not Windows execution.
- Isolated Xvfb production-adapter harness: **8/8 scenarios pass** using protocol 2 and software WebGL. This protects Linux behavior; it does not verify Windows.
- Renderer acceptance covers Windows capture defaults, explicit legacy selection, save/reload and browser conversion without input. Production app build and Electron IPC/persistence smoke pass locally.

## Windows runtime evidence

The Windows CI job builds the MSVC helper and fixture, runs its six Rust tests (including simulated partial keyboard/mouse insertion), and attempts five opt-in desktop matrix cases. Missing interactive-desktop/graphics prerequisites are recorded as incomplete, never as native passes. The report/artifact must be inspected before claiming runtime coverage.

Physical Windows 11 x64, actual mixed monitor DPI/negative-origin displays, hardware GPU capture, privilege/permission revocation and installed NSIS identity remain qualification gaps. The roadmap status is **implemented**, not fully platform-verified. UIA/element picking and passive direct recording remain separate N05/N08 work.
