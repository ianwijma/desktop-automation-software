## Compatibility and limits

Workflow format remains version 2. No database migration, new IPC method, provider behavior, or native backend is introduced. Child input defaults are editable JSON values, not a required-input schema. Advanced JSON editing remains available, including unsupported schema features. Renaming/removing schema properties with name-dependent advanced constraints requires coordinated JSON edits.

This report establishes local editor and engine behavior. It does not qualify live models, new native platforms, or installers. Recording drafts/review remain R01, graph insertion R02, and provider conformance A04.
