# N06 implementation evidence — 2026-10-27

N06 adds explicit `ax` semantic locators to the existing editor and IPC contract. The macOS bridge resolves request-local public AX objects under a unique owner/window and checks PID/parent ownership, consent, session, modal state, secure subroles and supported operations. See [native locator guide](../native-locators.md#macos-ax-targeting-n06).

## Verification scope

Portable adapter tests exercise AX routing without coordinate/capture fallback, wrong-backend rejection, permission error propagation and Retina pixel-to-point mapping/stale display scale rejection. Renderer acceptance runs the semantic picker/tester, persistence, stale-response and keyboard journeys for both Windows and macOS with a controlled API. These checks do not establish Apple provider behavior.

The AppKit matrix executes four extra native scenarios per content scale (eight additions): picker/movement/invoke, Unicode value/read and unsupported action, duplicate/disabled/secure/read-only policy, and modal/removed controls. The fixture observation endpoint cannot perform the AX actions being tested. Hosted run results are recorded in the PR; unavailable checks remain incomplete, not passing evidence.

This host is Linux. Objective-C compilation, real AX effects and linked framework selftests require the hosted macOS job. Actual denied/revoked Accessibility consent (including while a provider request is in flight), regrant/restart, locked sessions, installed-app identity, mixed displays/Retina and non-AppKit provider behavior remain manual qualification gaps. The adapter's injected permission error proves error handling only.

## Manual permission acceptance

In a disposable macOS 14+ session, grant Accessibility to the installed Relay/helper identity, inspect and invoke the fixture, then revoke consent in System Settings. Inspect/Read/Type/Invoke must return PERMISSION_DENIED without changing the fixture or using CGEvents. Repeat revocation while a request is pending; record any already-running provider effects separately. Regrant consent and restart the helper before retesting. Lock/unlock and repeat. Record exact OS/artifact identity and observed results in the [manual report](../manual-test-report.md).

N06 is implemented pending full provider/permission qualification. N07 adds Linux AT-SPI; direct macOS recording remains N09.
