## Acceptance evidence

- [Discovery tests](../../tests/value-references.test.ts) cover input defaults, typed nested paths, stable node IDs, safe path handling, conditional branches, error paths, overwritten/conditionally assigned variables, detector waits, Loop scope, and flow completion.
- [Execution tests](../../tests/value-authoring.test.ts) run saved/reloaded flows through the real engine. Exact references preserve strings, numbers, zero, booleans, false, objects, arrays, and null; interpolation remains text. Detector references survive a source rename and produce guarded center coordinates. Loop item/index mappings retain types.
- [Reference UI smoke](../../scripts/reference-picker-smoke.mjs), called by the main UI smoke, selects detector results without advanced JSON, uses keyboard selection/cancel/focus restoration, verifies that modal shortcuts do not change the graph, and checks stable references after rename/save/reload.
- The same UI checks cover missing-node and conditional-path feedback, typed literal/reference round-trips, negative decimal editing, restoring a previous null literal, object/array property editing, and Loop-only item/index choices.
- The picker searches the complete discovered option set while displaying at most 100 results at a time. Large/deep structured values keep a JSON editing fallback.
- UI smoke writes synthetic screenshots to `test-results/relay-reference-picker.png` and `test-results/relay-typed-object.png`; CI's existing artifact upload includes these files.

## Compatibility and limits

Workflow schema remains version 2. References and execution behavior are unchanged; no new runtime permission or IPC method is introduced. Unknown custom output properties can still be entered manually; inferred types are hints and runtime inputs may override defaults.

Availability warnings cannot prove that an application, detector, or model returns an optional property. Runtime checks remain authoritative. Full flow-interface editing, mode-specific structured inspectors, and an AI-output schema builder remain U02 work. No new native platform, installer, or live-provider qualification is claimed.
