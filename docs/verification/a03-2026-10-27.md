# A03 implementation evidence — 2026-10-27

A03 adds request-scoped cancellation, model/timing/available-usage diagnostics, curated error categories, a bounded cached OpenRouter catalog and native allowlisted metadata export. See [operator guide](../ai-diagnostics.md).

## Local evidence

Typecheck and 372 TypeScript tests across 29 files pass locally. Coverage includes actual Ollama/SDK/Jev adapter metadata, missing provider fields (without SDK fallback identities/zero-filled usage), cancellation despite a late success, request/concurrency isolation, actionable redacted errors, metadata export allowlists, advertised versus enabled/verified capability handling, cached/offline search, stale metadata, bounded response bodies and cancelled/superseded refreshes.

Production build and source Electron smoke exercise the real preload/main/utility/SQLite boundary against local HTTP. The journey cancels a held Ollama request, checks request-ID validation and stale evidence, and exports a real JSON file using an intercepted native save-dialog choice. Export contents are read back and checked for model/usage evidence and exclusion of endpoints, private names, response text, images and raw payload markers. Cached/manual catalog IPC makes no external request.

Renderer acceptance checks distinct operation results, cancellation/export controls, stale/late catalog data, selection without capability changes, cancelled refresh and offline manual Model ID saving. The controlled API establishes UI behavior, not live provider capability.

A credential-free read of the official model catalog returned HTTP 200 with 462 entries within the 8 MiB limit when implementing this slice. CI uses mocked metadata and local HTTP only; no provider inference or paid request is made. Current OpenRouter fields were checked against its official model/API documentation. Hosted run results are recorded in the PR.

## Limits

Live cloud/local model conformance, exact runtime versions, usage/billing semantics, cold starts and real-image accuracy remain A04 qualification. Catalog advertisements do not verify model operations or custom endpoint policies. Provider cancellation is best effort after acceptance and does not prove a request was unbilled. Existing native/installer/manual qualification gaps remain unchanged.
