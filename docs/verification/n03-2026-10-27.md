# N03 implementation evidence — 2026-10-27

N03 links a persistent ScreenCaptureKit/public Accessibility bridge into the Rust helper, replacing screenshot subprocesses and title-dependent AppleScript. Native protocol stays 2 with additive macOS permission/identity/display-scale diagnostics. See the [backend guide](../macos-native.md).

## Local evidence (Linux host)

- TypeScript check and **317 tests across 25 files** pass. New coverage checks Retina pixel-to-point mapping, stale frames after a display-scale change, real helper capability serialization and diagnostic path redaction.
- **Six portable Rust tests** pass, including macOS permission/session/capture error mapping and bundle identity preservation.
- Production native/application builds and Electron IPC/persistence smoke pass.
- The production-adapter Xvfb harness passes **8/8 desktop scenarios** with software WebGL. This is Linux regression evidence, not macOS native qualification.

## Remaining qualification

Synthetic renderer/content scaling is **not actual Retina or mixed OS scaling**. Hosted Metal capture proves observed Metal pixels in that session; the report deliberately leaves `hardwareGpuQualified: false`. Representative physical GPU applications and actual Retina/secondary/negative-origin/mixed-scale display arrangements remain unqualified.

Denied/revoked permission recovery, lock/unlock and fast user switching, source closure/device interruption beyond minimization, identical-geometry AX ambiguity in a real application, and installed/signed app/helper identity remain manual acceptance gaps. Use the [manual test report](../manual-test-report.md) to record those environments and observations. CI without grants reports incomplete, never native success.

N03 is **implemented and verified in the hosted session above**, not fully platform-qualified. N06/N09 AX selectors/direct recording and D01–D03 distribution remain separate work. The next implementation slice is N04; A01 can proceed independently.
