# C02 image attachments evidence — 2026-10-29

C02 adds local file/paste/drop imports, one-time chosen desktop-window capture, prepared-image preview and explicit image selection/reuse to the Flow assistant. It builds on C01 and leaves graph review/binding/Apply (C03), durable chat history/retention (C04), real provider qualification (A04) and the remaining native/distribution roadmap open.

## Automated evidence

Typecheck and 422 TypeScript tests across 32 files pass locally. Seventeen attachment/image cases cover actual PNG/JPEG/WebP decoding, EXIF orientation and metadata removal, byte/decompression/dimension/compressibility limits, corrupt/truncated/nonraster input, APNG and real animated WebP rejection, binary-only descriptors, unique IDs, session ownership, explicit reuse, no implicit history, four-image, queued binary admission and concurrent preparation reservations, expiry/deletion, changed prepared files, late capture/session close and chosen desktop-target freshness. Existing authoring/provider/engine/native/storage regressions remain included.

The full renderer acceptance suite passes. The new controlled-API journey exercises file selection, paste, drop, explicit capture, local prepared previews, navigation retention, four-image limits, text-only vision rejection, explicit Send/reuse, cancellation, clear, unavailable capture, partial import errors and desktop-only browser preview behavior. Focused follow-up verification includes full-size preview keyboard/focus behavior, lazy earlier-image previews and Ctrl-S isolation. Dark/light screenshots are saved with the normal CI artifacts.

Production build and Xvfb application smoke pass through actual sandboxed preload/main/utility/SQLite boundaries. The new loopback journey checks real binary input/output, upright stripped prepared PNG, local image-only clarification, explicitly selected image bytes at the production Ollama HTTP adapter, the actual composer file/preview/Send/reuse journey, excluded history images, wrong-session/deleted references, text-only rejection before inference and actual HTTP cancellation on image deletion. Saved flows/targets/schedules/runs are compared before/after and remain unchanged by authoring.

The isolated X11 native fixture also exercises chosen-window capture through the real helper. It produces exactly one local draft attachment, exposes no runtime frame/native identity and leaves the fixture's button/text field unchanged. Hosted CI additionally runs source smoke on each OS and packaged application smoke on Linux/macOS. Final run links, exact head and downloaded artifact results are recorded in the PR.

## Remaining qualification

Controlled renderer and loopback/model-response fixtures do not establish real model quality, image grounding, actual cloud policy, GNOME/KDE portal or native permission/hardware behavior. Existing platform qualification gaps remain in their native reports. Prepared scratch files and the temporary conversation are not durable chat history. This slice has no Apply authority and does not promote images to workflow assets; C03/C04 retain those requirements.
